Personvern

Sist oppdatert: 2. november 2026

Appen samler ikke inn data

Minh Nguyen Studios mottar ingen dokumenter eller bruksdata gjennom Ablagefuchs. Det finnes ingen konto, reklame, telemetri, analyse eller skysynkronisering.

Lokal lagring og tekstgjenkjenning

Dokumentkopier og databasen lagres lokalt på PC-en din under %LOCALAPPDATA%\MinhStudios\Ablagefuchs. Tekstgjenkjenningen kjører lokalt med Windows OCR eller en installert Tesseract. Beskytt Windows-kontoen og stasjonen din. Du sletter selv data, sikkerhetskopier og eksporter på enheten din.

Eksporter og andre apper

ZIP-sikkerhetskopier, mappe- og CSV-eksporter og ICS-kalenderfiler inneholder dataene dine. Du bestemmer hvem du deler dem med. Åpning av dokumenter skjer i den aktuelle appen; kjøp skjer via Microsoft Store.

Dette nettstedet

Dette nettstedet driftes på GitHub Pages (GitHub, Inc.). Ved besøk behandler GitHub tilkoblingsdata som trengs for å levere sidene og beskytte mot misbruk, for eksempel IP-adressen din; data kan overføres til USA. Rettsgrunnlaget er vår berettigede interesse i sikker levering (GDPR art. 6 nr. 1 bokstav f). Detaljer står i GitHubs personvernerklæring, lenket nedenfor. Nettstedet bruker ingen informasjonskapsler, sporere, eksterne skript eller skrifttyper.

Kontakt

Hvis du sender oss e-post, behandler vi meldingen din for å besvare henvendelsen. Ikke send konfidensielle dokumenter eller sikkerhetskopier. Behandlingsansvarlig: Michel Nguyen, Minh Nguyen Studios, Windmühlenstr. 74, 07937 Zeulenroda-Triebes, Tyskland.
