Windows用の契約書・期限管理アプリ

期限を把握し、契約書をすぐ手元に。

契約書、請求書、大切な手紙をPCでひとまとめに。コピーを保存し、オフラインで文字を認識して期限を管理できます。アカウントもクラウドも不要です。

  • PC内に保存
  • 元のファイルを保持
  • 定期購読なし
  • 17言語対応

Microsoft Storeで見る使い方を見る

Microsoft Store向けに準備中です。公開前にストアへのリンクを追加します。

3ステップで書類を整理

  1. 1

    書類を追加

    PDF、スキャン画像、写真をドラッグ＆ドロップするか、フォルダーごと追加します。コピーを検証し、同一ファイルの重複を検出します。

  2. 2

    確認して整理

    オフラインで文字を認識し、提案された種類、日付、差出人を確認してタグを追加します。保存内容は自分で決められます。

  3. 3

    検索して期限を管理

    単語の先頭部分やアクセント記号なしで検索できます。期限を入力し、Windows通知を何日前に表示するか設定します。

大切な情報をすぐ手元に

オフライン文字認識

Windows OCRでスキャン画像や写真を検索可能にします。インストール済みのTesseractを代替として利用できます。

便利な全文検索

タイトル、差出人、タグ、認識した本文を検索。単語の先頭部分やアクセント記号なしでも探せます。

期限を一覧表示

解約期限、契約終了、保証、支払い、有効期限。期限切れと今後30日分を一覧で確認できます。

解約期限の計算

契約終了日から予告期間を引いて解約期限を計算。契約書の情報は自分で入力します。

自分に合うリマインダー

単発・繰り返しの期限と通知のタイミングを設定。ICSファイルでカレンダーにも出力できます。

重複を防いで整理

書類の種類、タグ、ごみ箱で整理。同一ファイルを二重に保存しません。

データはあなたのもの

ローカル保存

クラウド、アカウント、広告、トラッキングはありません。書類はディスク上の通常のファイルです。

元のファイルを保持

検証したコピーを使います。元のファイルを変更、移動、削除しません。

バックアップと出力

データベースとすべての文書を含み、書き込み後に検証します。別のドライブに保管してください。使用中は1日最大1回、データフォルダーにデータベースのバックアップを作成します（最新14件）。文書ファイルは含まれません。

Ablagefuchsの画面

取り込みからバックアップまで：本文を確認し、解約日を計算して、確認した期限を管理します。

macOS上のAvalonia Headlessによるローカルの下書き画像です。Windowsのネイティブ画像と実際に表示されたPDFプレビューは未確認です。

じっくりお試しください

30日間または100書類まで、先に達するまで試用できます。その後は買い切りで新しい書類の取り込みを続けられます。定期購読はありません。

試用後も検索、期限、リマインダー、バックアップ、出力は無料で利用できます。新しい書類の取り込みのみ制限されます。

よくある質問

元のファイルは残りますか？

はい。検証したコピーを保存し、元のファイルは元の場所で変更せずに保持します。

ファイルはどこに保存されますか？

PC内の%LOCALAPPDATA%\MinhStudios\Ablagefuchsに保存されます。書類のコピーはディスク上の通常のファイルで、クラウド同期はありません。

文字認識はどう動きますか？

Windows OCRとインストール済みの言語パックを使い、PC内で処理します。インストール済みのTesseractを代替として利用できます。

アプリを閉じていても通知されますか？

Windows はアプリ終了中も予約済みの通知を表示できます。Windows の通知を有効にしてください。400日以内の最大200件の通知を予約します。定期的にアプリを開き、予約を更新してください。日付は入力内容に基づきます。確認してください。

解約期限を確認してくれますか？

いいえ。入力した情報を保存し、その情報で計算します。法定期限、契約条件、保存義務を確認するものではなく、法律・税務の助言も行いません。

試用期間が終わるとどうなりますか？

30日または100書類で試用が終了します。買い切りで追加の取り込みを解除できます。既存書類の検索、期限、リマインダー、バックアップ、出力は引き続き利用できます。
