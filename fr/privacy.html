Confidentialité

Mise à jour : 2 novembre 2026

L’app ne collecte aucune donnée

Minh Nguyen Studios ne reçoit aucun document ni donnée d’utilisation via Ablagefuchs. Sans compte, publicité, télémétrie, analyse ni synchronisation cloud.

Stockage et OCR locaux

Les copies et la base sont sur votre PC sous %LOCALAPPDATA%\MinhStudios\Ablagefuchs. L’OCR utilise Windows ou Tesseract installé, en local. Protégez votre compte Windows et votre disque. Vous supprimez vous-même données, sauvegardes et exports sur votre appareil.

Exports et autres programmes

Sauvegardes ZIP, exports de dossiers et CSV et calendriers ICS contiennent vos données. Vous décidez à qui les transmettre. L’ouverture des documents dépend du programme utilisé, l’achat du Microsoft Store.

Ce site

Ce site est hébergé sur GitHub Pages (GitHub, Inc.). Lors de votre visite, GitHub traite les données de connexion nécessaires pour fournir les pages et les protéger contre les abus, comme votre adresse IP ; des données peuvent être transférées aux États-Unis. La base juridique est notre intérêt légitime à fournir le site de manière sûre (art. 6, par. 1, point f du RGPD). Les détails figurent dans la déclaration de confidentialité de GitHub, liée ci-dessous. Le site lui-même ne dépose aucun cookie et n’utilise ni traceurs, ni scripts ou polices externes.

Contact

Votre courriel est traité pour répondre à votre demande. N’envoyez pas de documents confidentiels ou de sauvegardes. Responsable : Michel Nguyen, Minh Nguyen Studios, Windmühlenstr. 74, 07937 Zeulenroda-Triebes, Allemagne.
