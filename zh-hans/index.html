三步建立井然有序的档案

  1. 1

    拖入文档

    通过拖放或整个文件夹添加 PDF、扫描件和手机照片。Ablagefuchs 会校验副本并识别重复文件。

  2. 2

    检查并整理

    离线识别文字，检查建议的类型、日期和发件人，并添加标签。保存什么由您决定。

  3. 3

    查找并记住

    可按词语开头搜索，也可不带重音符号搜索。添加期限，并选择 Windows 通知的提前天数。

重要功能，触手可及

离线文字识别

Windows OCR 让扫描件和照片可被搜索。已安装的 Tesseract 将作为备用方案。

好用的搜索

可在标题、发件人、标签和识别出的文字中搜索，也支持词语开头和不带重音符号的写法。

期限一目了然

解约日、合同到期、保修、付款和失效日期：查看已逾期的事项以及接下来的 30 天。

小巧的解约计算器

合同到期日减去通知期，即得到最晚解约日期。数字由您根据合同自行输入。

按您的方式提醒

一次性或重复的期限，提前多久提醒由您选择。还可将 ICS 文件导出到您的日历。

整齐且无重复

文档类型、标签和回收站帮助您保持整洁。相同的文件不会被重复保存。

您的档案始终属于您

本地数据

没有云端、账户、广告或跟踪。您的文档是磁盘上的普通文件。

原件保持不变

Ablagefuchs 使用经过校验的副本。您的原始文件绝不会被更改、移动或删除。

备份与导出

使用期间，应用每天最多创建一份数据库备份。其中不含文档文件；请创建完整的 ZIP 备份，并将副本保存在另一个驱动器上。

Ablagefuchs 一览

从导入到备份：检查文字，计算解约日期，并时刻关注已确认的期限。

常见问题

Ablagefuchs 多少钱？

在 Microsoft Store 一次性购买 24,99 €，无需订阅。备份和导出是应用的一部分；您的数据属于您。

我的原件会保留吗？

会。Ablagefuchs 保存一份经过校验的副本，原始文件保持不变，仍在原来的位置。

我的文件存储在哪里？

本地存储在您电脑上的 %LOCALAPPDATA%\MinhStudios\Ablagefuchs 下。文档副本是磁盘上的普通文件，没有云同步。

文字识别是如何工作的？

它借助 Windows OCR 和已安装的 Windows 语言包在本地运行。已安装的 Tesseract 可作为备用方案。

应用关闭时会显示提醒吗？

即使应用已关闭，Windows 也可以显示已安排的提醒。请启用 Windows 通知。在 400 天内最多安排 200 个提醒时间；请定期打开应用以更新计划。日期来自您的输入，请自行核对。

Ablagefuchs 会检查我的解约通知期吗？

不会。应用保存您输入的信息，并据此计算。它不会检查法定期限、合同条款或保管义务，也不提供法律或税务建议。

Ablagefuchs支持隐私法律信息
