앱은 데이터를 수집하지 않습니다

Minh Nguyen Studios는 Ablagefuchs를 통해 문서나 사용 데이터를 받지 않습니다. 계정, 광고, 원격 측정, 분석, 클라우드 동기화가 없습니다.

로컬 저장과 텍스트 인식

문서 사본과 데이터베이스는 PC의 %LOCALAPPDATA%\MinhStudios\Ablagefuchs 아래에 로컬로 저장됩니다. 텍스트 인식은 Windows OCR 또는 설치된 Tesseract로 로컬에서 실행됩니다. Windows 계정과 드라이브를 보호하세요. 데이터, 백업, 내보내기는 직접 기기에서 삭제합니다.

내보내기와 다른 앱

ZIP 백업, 폴더 및 CSV 내보내기, ICS 캘린더 파일에는 사용자의 데이터가 들어 있습니다. 누구와 공유할지는 직접 결정하세요. 문서 열기는 해당 앱의 규정을, 구매는 Microsoft Store의 규정을 따릅니다.
